# 学ぼう！にほんご中級 — Интерактивный тест (Уроки 21–25)

Интерактивный веб-тест по лексике учебника **«学ぼう！にほんご中級» (第21課〜第25課)** — 103 вопроса с умным повторением ошибок.

## 🌟 Особенности
- 🔁 **Интервальное повторение**: при ошибке вопрос автоматически повторяется через 3 вопроса для закрепления.
- 📚 **Перевод слов и предложений**: показывает исходную форму, фуригану, перевод слова и контекст предложения на русском языке.
- 🔘 **Отдельные кнопки для каждого урока**: мгновенное переключение между уроками (21, 22, 23, 24, 25 или все сразу).
- 🔊 **Озвучка (TTS)**: прослушивание произношения японских предложений.
- ⌨️ **Управление с клавиатуры**: выбор ответов клавишами 1-4, переход по Enter.
- 🌓 **Тёмная и светлая тема**.
